## Prompt 库应该像组件库一样管理

好的 Prompt 不只是一次性的提问，而是一套可以复用、迭代和版本管理的工作资产。设计师可以把常用提示词按场景拆分，例如调研、概念、文案、视觉、动效和验收。

![Prompt Library 封面](/images/prompt-library.svg)

## 一个稳定结构

```text
角色：你是一名资深品牌设计师
任务：为一个新消费品牌生成视觉方向
上下文：品牌关键词、目标用户、竞品、已有素材
限制：不要使用的颜色、不要出现的风格、输出长度
格式：用表格输出，包含方向名、关键词、优点、风险
```

## 常见误区

- 只给一句模糊需求，期待 AI 自动理解审美标准。
- 没有告诉 AI 什么不要做，导致输出过度发散。
- 每次重新写 Prompt，无法复用已经验证有效的结构。

把 Prompt 当成设计系统的一部分管理，AI 的输出质量会明显更稳定。
